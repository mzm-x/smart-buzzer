## System Architecture

### Order Management System

**File Structure:**
```
/order/
  submit.php           - Client order form (v4.2)
  manage.php           - AM dashboard (v5.1)
  process.php          - Form handler (v3.2)
  open-sheet.php       - Spreadsheet creator (v3.2)
  login.php            - AM authentication (v3.1)
  logout.php           - Session destroy
  config.php           - Configuration (v1.4)
  auth.php             - Auth handler (v1.2)
  functions.php        - Helper functions (v1.2)
  log.php              - Submission analytics dashboard (v1.3)
  get-orders.php       - AJAX fetch orders API (v1.1)
  delete-orders.php    - Bulk delete orders API (v1.1)
  update-status.php    - Status update API (v1.0)
  save-tnc.php         - TNC save API (v2.1)
  index.php            - Entry redirect
  composer.json        - PHP dependencies

  /data/
    orders.json        - Central order database
    tnc.json           - Terms & Conditions data
    rate_limit.json    - Rate limiting data
    blocked_ips.json   - Blocked IP addresses

  /credentials/
    service-account.json - Google API key

  /vendor/
    autoload.php       - Autoloader
    google/apiclient/  - Google API Client
```

**Technology Stack:**
- **Frontend:** HTML, Tailwind CSS, JavaScript, Canvas Confetti
- **Backend:** PHP 8.3+
- **Database:** JSON (file-based with file locking)
- **API:** Google Sheets API v4
- **Authentication:** Session-based with bcrypt (cost 12)
- **Design:** Apple-style minimalist

**Security Features:**
- Bcrypt password hashing (cost 12)
- Session timeout (30 min dashboard, 90 days login persistence)
- Rate limiting (10 submissions/hour, 5 failed logins/15 min)
- CSRF protection on all POST endpoints
- Indonesia IP restriction on admin pages
- Permanent IP block after 3 failed login attempts
- Input sanitization
- File locking for concurrent writes
- Secure headers (X-Content-Type-Options, X-Frame-Options)
