--------------------------------------------------------------------------------
1. WHAT THIS IS
--------------------------------------------------------------------------------
A standalone landing page that sells Google reviews on the SHOW-UP model
(not the old "stay" model). Cloned from /promo/ then converted.

Core promise (the honest frame the whole page carries):
  "You pay for reviews that SHOW UP on your Google listing. Whether a review
   stays long-term is decided by Google's algorithm and nobody can control that.
   The only guarantee is a 7-day per-review free replacement. It is what it is,
   and we sell it honestly."

Ops fact behind the model: average submit -> show-up rate is ~24%.
So to deliver the show-up count we SUBMIT far more, gradually.

--------------------------------------------------------------------------------
4. GUARANTEE MODEL (show-up)
--------------------------------------------------------------------------------
1) A review counts as delivered the moment it shows up on the listing (1 = 1).
2) Each review carries its OWN 7-day window starting the day it shows up
   (not after the whole order completes).
3) Drops within 7 days -> replaced free, ONE replacement per review.
4) Stays past 7 days -> final. Drops after 7 days -> NOT replaced.
5) A replacement that later drops -> NOT replaced again.
6) We do NOT guarantee how many stay long-term (Google's algorithm).

Compliance: avoid "zero drops / no bans / guaranteed stay". We promise
replacement, not permanence.

5. PAYMENT FLOW  (NO Fanbasis / no third-party gateway)
--------------------------------------------------------------------------------
index.php order form (biz + WhatsApp + email + package)
   -> submitOrder(): fires begin_checkout + add_payment_info (GA4),
      InitiateCheckout (FB+TikTok), writes customer_data.log (FORM_SUBMIT),
      saves user_data to localStorage bridge
   -> redirect to  payment.php?pkg=<key>&biz=<business>

payment.php:
   - Shows ZELLE instructions:  #5032671660  /  Ghirish Pokardash  /  amount
   - Customer uploads proof of payment (image or PDF)
   - Email + WhatsApp prefilled from localStorage bridge (hidden email field)
   - On successful upload -> fires PURCHASE (GA4 purchase + FB Purchase +
     TikTok CompletePayment), then shows "Proof received" success state
   - NOTE: the "Pay with Crypto" block was REMOVED from payment.php (Zelle only).
     index.php copy still mentions "Zelle or Crypto" in a few spots (pricing
     note, order box, FAQ, trust badge) — left as-is unless told to drop Crypto
     everywhere.

upload.php:
   - Validates CSRF (session token from payment.php), file type
     (jpg/png/webp/pdf), size (<= 8 MB)
   - Stores file to /proofs/  (HTTP-denied via .htaccess)
   - Appends order record to proofs_log.tsv

Payment policy: advance payment, ALL SALES FINAL, refunds = store voucher only.
